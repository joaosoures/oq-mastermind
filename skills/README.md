# Skills do Projeto

Esta pasta armazena documentos que definem as regras permanentes e diretrizes de desenvolvimento deste projeto.

## O que são as Skills?
Cada arquivo `.md` nesta pasta representa uma "skill" — um conjunto de instruções, padrões de arquitetura, preferências de design ou regras de negócio que devem ser seguidas de forma consistente em todo o código.

## Como usar
Antes de iniciar qualquer alteração de código, criação de novas funcionalidades ou correções de bugs, você deve consultar as skills aplicáveis para garantir que o trabalho esteja alinhado com as diretrizes do projeto.

*Nota: Este é um documento vivo e deve ser atualizado conforme o projeto evolui.*
